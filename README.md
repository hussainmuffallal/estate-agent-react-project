# Estate Agent Web App

This website provides the facility to buy a properties based on their interest.

## Buyers has the facility to:

*   View the properties
*   Add to favourites
*   Remove from favourites
*   Availabity of floor plan
*   Buyers can filter and sort the properties.

## 🚀 Local Development

To run this project locally, follow these steps:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/hussainmuffallal/estate-agent-react-project.git

2. **Navigate to the directory:**
    ```bash
    cd estate-agent-react-project

3. **Install dependencies:**
    ```bash
    npm install

4. **Start the development server:**
    ```bash
    npm run dev

The site will be available at http://localhost:5173/estate-agent-react-project/
